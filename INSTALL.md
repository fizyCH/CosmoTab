# Cosmic New Tab

## Firefox

1. Откройте `about:debugging`.
2. «Этот Firefox» → «Загрузить временное дополнение».
3. Выберите `manifest.json` в корне проекта.
4. Для стартовой страницы: Настройки Firefox → «При запуске» → «Открывать домашнюю страницу».

## Chrome / Chromium

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `chrome`.

Chrome не поддерживает Firefox-овский относительный `homepage` в `chrome_settings_overrides`, поэтому для Chromium используется отдельная сборка без этого ключа. Новая вкладка работает через `chrome_url_overrides.newtab`.

После изменения общих файлов в корне пересоберите Chrome-версию:

```bash
node build-chrome.js
```

## Firefox для Android

Firefox Android не поддерживает `chrome_url_overrides.newtab`, поэтому заменить системную новую вкладку на Android нельзя. Вместо этого CosmoTab открывается кнопкой расширения:

1. Установите подписанный XPI (через AMO или self-distributed).
2. Нажмите иконку CosmoTab на панели или в меню расширений.
3. Страница откроется в обычной вкладке. Повторное нажатие переключит на уже открытую вкладку CosmoTab.

При первой установке на Android CosmoTab открывается автоматически.

Минимальные версии: Firefox 140 и Firefox Android 142 — это требование `data_collection_permissions` в манифесте.

## Погода

Основной источник — `wttr.in`, резервный — Open-Meteo. Город выбирается из списка в настройках. Если погода не загрузилась, нажмите на карточку погоды, чтобы повторить запрос. При ошибке виджет показывает «Нет данных · обновить» / «Unavailable · retry», а не бесконечную загрузку.

## Плеер

Плеер оформлен в стиле liquid glass: многослойное стекло, блики и мягкое свечение. Доступны кнопки «Предыдущий трек», «Пауза / Играть» и «Следующий трек». Пауза не скрывает плеер — его можно снова запустить той же кнопкой. Переключение треков работает на сайтах, где есть соответствующие кнопки или обработчики медиа-клавиш.

## Настройки

Шестерёнка в правом верхнем углу: язык RU/EN, расположение, поисковик, освещение планеты, город и единицы температуры, возврат стандартных закладок.

Если язык ещё не меняли вручную, интерфейс открывается на английском. После явного выбора язык сохраняется.

## Расположение

В настройках, раздел «Интерфейс → Расположение», можно выбрать:

- **Поиск внизу, плеер сверху** — стандартный вид;
- **Поиск вверху, плеер внизу** — поисковая строка поднимается наверх, а плеер и погода опускаются вниз.

Выбор сохраняется и применяется сразу. На телефоне плеер и погода встают под закладками, чтобы не перекрывать их.

## Освещение Земли

Доступны четыре режима:

- **Авто (по времени)** — сезонный закат/восход по локальным часам;
- **День** — планета полностью освещена, огней нет;
- **50 / 50** — тень делит планету пополам, огни на тёмной стороне;
- **Ночь** — вся видимая сторона в тени, горят огни городов.

Ручные режимы не зависят от времени. Авто стоит по умолчанию.

## Поиск

Обычный поиск использует выбранный поисковик. ИИ-режим открывает Google AI Mode (`google.com/search?...&udm=50`), а кнопка истории — `google.com/ai`.

## Картинки для ИИ и Объектива

В строке поиска есть кнопка с картинкой. Также изображение можно вставить из буфера обмена (`Ctrl+V`) или перетащить прямо на строку поиска.

После выбора картинка не отправляется сразу: внутри строки поиска появляется превью с кнопками отправки и удаления. В строке поиска можно написать вопрос к изображению. Нажмите `Enter` или кнопку со стрелкой, чтобы отправить.

Куда отправить картинку, зависит от переключателя ИИ:

- **ИИ включён** — изображение и текст вопроса уходят в Google AI Mode;
- **ИИ выключен** — открывается поиск по изображению в Google Lens.

Если вопрос не написан, изображение отправляется без дополнительного текста. Картинка отправляется в Google только после нажатия кнопки отправки или `Enter`.

## Закладки

По 9 закладок на страницу, переключение стрелками и точками. Любую закладку, включая стандартную, можно удалить. Стандартные возвращаются кнопкой в настройках.

В окне добавления можно выбрать **Закладка** или **Папка**. Папка открывается прозрачной сеткой 3×3 на месте девяти вкладок, а её название показывается по центру над папкой. Нажмите на название, чтобы переименовать. Внутри папки есть своя кнопка добавления; закладки можно перетаскивать в папки, а чтобы вынести закладку наружу, перетащите её за пределы папки. Если перетащить одну закладку на другую, сразу создастся новая папка с ними двумя. Клик мимо вкладок закрывает папку.

В настройках также есть экспорт закладок в JSON и импорт из JSON: импорт добавляет закладки, пропуская уже существующие адреса.
